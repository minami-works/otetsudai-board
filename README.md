# おてつだいボード

小学生のお手伝い・テストの点数から、毎月のおこづかいを計算する家庭用のWebアプリです。
子どもはマンスリーダイアリーにシールを貼り、親がこのボードに記録して金額を出す、という使い方を想定しています。

## 機能

- **固定給**：学年 × 100円。毎年4月に学年が自動で1つ上がります
- **お手伝い**：お風呂掃除・洗濯物をたたむ・朝学習、内容を書き込める「その他のお手伝い」
- **ペットボトル**：10本で30円。端数の本数は翌月に持ち越し
- **テスト満点ボーナス**：国・算・理・社。100点満点で100点、50点満点で50点をとったときのボーナス
- **スマイルゼミ**：夏・冬・春のテストの点数がそのまま金額（小数点以下は切り捨て）
- **前借り**：内容と金額を書き込むと、その月のおこづかいから差し引きます
- **スタンプカレンダー**：日ごとにかせいだ金額と、お手伝いの種類が色で表示されます
- **年度のまとめ**：4月〜3月の「もらった合計」「まだもらっていない」「前借りの合計」と月ごとのグラフ
- **バックアップ**：記録をJSONファイルで保存・読み込み

金額はすべて画面下の「おうちの人の設定」から変更できます。

## データの保存先

記録はブラウザの `localStorage` だけに保存され、サーバーには送信しません。
そのため、別の端末やブラウザでは記録を共有できません。月に1回などの頻度で、バックアップを保存しておくと安心です。

## 使った技術

- HTML / CSS / JavaScript（ライブラリなし）
- CSS変数でカラーを管理し、`prefers-color-scheme` でダークモードに対応
- スマホ幅〜PC幅のレスポンシブ対応
- Google Fonts（Mochiy Pop One / Zen Maru Gothic）

## ファイル構成

```
index.html      … 画面の骨組みと設定フォーム
css/style.css   … 見た目（色・レイアウト）

```

## 公開方法（GitHub Pages）

1. このフォルダをGitHubのリポジトリにpushする
2. リポジトリの Settings → Pages で、Branch を `main` / `(root)` にして保存
3. 数分後に表示されるURLで使えます
